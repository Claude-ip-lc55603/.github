<h2>一、把账单拆成四块</h2>
<p>四块分别是：线路月费、抖动带来的时间损耗、撞车导致的返工、以及换服务商时的重建成本。多数人只算第一块，所以总觉得贵的方案不划算；四块都算过之后，结论经常反过来。</p>
<p>拆账的目的不是求精确数字，而是找出哪一块在你这里最大。号多的团队，第二块通常最大；号少的团队，第一块占比最高。先认清自己的大头在哪，再决定优化方向。</p>
<h3>四块的量级参考</h3>
<p>线路月费：每条每月几十到一百多元。时间损耗：按每小时人力成本乘损失工时。撞车返工：每个受牵连号按半天到一天计。重建成本：换服务商一次，按全员半天计。前两项是持续性支出，后两项是一次性支出。</p>
<h3>为什么一次性支出也要摊进月账</h3>
<p>换服务商的成本不是零：重新下单、重新验环境、重新登录、观察一周。这笔账摊到三个月，等于每个月多付了一次小规模的线路费。频繁换供应商的团队，往往在这块悄悄流失了最多预算。</p>

<h2>二、显性支出：线路本身的价格</h2>
<p>单条静态住宅出口的参考价，按城市和带宽分档，一般每月几十元到一百多元，双 ISP 配置会再上浮两到三成。这个数字最透明，也最容易被拿来做对比，但它只占四块里的一块。</p>
<p>比价时要统一口径：是否含独享、是否含换线、是否含带宽上限、计费是按自然月还是按三十天。四个口径不一致，价格高低就没意义。同样写"99 元/月"，含两次换线和一次都不含，实际差一倍的可用性。</p>
<h3>单价低的三个常见代价</h3>
<p>同址挂着多个号、出口带宽被共享、换线要排队。三项里最影响成本的是第二项，因为带宽抖动直接转化成工时损失，而且这种损失是每天都在发生的，不像换线是偶发。</p>
<h3>带宽上限要问绝对值</h3>
<p>不要问"够不够用"，要问"单条保障多少兆"。日常对话类任务的流量很小，但并发拉满时对延迟敏感。保障带宽写不清的，晚间高峰一定抖。</p>

<h2>三、隐性支出：速度抖动折算成工时</h2>
<p>抖动怎么折成钱？先量化现象，再乘工时。量化方式是记录一周内的首字响应时间，取中位数和九十分位，两者差距越大说明抖动越明显。</p>
<p>举例：中位数 1.2 秒、九十分位 6 秒，说明有一成的请求会慢五倍。按每天两百次请求算，其中二十次每次多等五秒，一天浪费一百秒；看起来不多，但如果每次慢都伴随一次重试，实际损失是三到五倍。</p>

<h3>为什么要看九十分位而不是平均值</h3>
<p>平均值会把偶发的长时间卡顿稀释掉，而人对卡顿的感受恰恰来自那几次长的。中位数告诉你常态，九十分位告诉你最坏的那一成。两个数一起看，才判断得出这条线适不适合长时间挂着。</p>
<h3>抖动的根源通常不在带宽</h3>
<p>多数抖动来自上游链路拥塞和同址其他用户的突发流量，而不是你买的带宽不够。所以换更贵的套餐不一定解决抖动，换一条同址人少的线往往更有效。</p>

<h2>四、撞车率怎么折成钱</h2>
<p>撞车指两条线路落到同一段地址、或者新拿到的地址带有别人留下的历史。前者是采购规模问题，后者是池子质量问题。两种撞车的成本表现不同：前者表现为批量异常，后者表现为个别号反复验证。</p>

<h3>池子大小与撞车率的粗略关系</h3>
<p>池子越大，重复概率越低，但不是线性关系。手头有二十个号时，池子从五百扩到两千，撞车率的下降已经不明显；从五十扩到五百，下降非常明显。所以小规模团队更该看池子下限，大规模团队更该看分配策略。</p>
<h3>一次撞车的成本怎么算</h3>
<p>按受影响号数算：每个号半天重配加一天观察，两个人分担就是一天半人力。二十个号里撞三条，等于四五天人力，按人力成本折，往往超过一个月线路费的差额。这就是为什么贵一点但池子大的方案，长期算下来反而便宜。</p>

<h3>结论依赖哪个变量</h3>
<p>依赖工时单价。人力成本越高、单个号的价值越大，越应该往独享走；人力便宜、号的价值低、可随时重开的，共享池的经济性反而成立。所以同样的账，两个团队算出来会完全不同。</p>
<h3>别忘了一次性支出</h3>
<p>上表只算月度持续性支出。如果某个方案每季度要换一次服务商，把重建成本摊进去，便宜方案的优势会被吃掉大半。这也是很多人"越换越贵"的原因。</p>

<h2>常见问答</h2>
<h3>只有五个号，也值得上独享吗？</h3>
<p>答：看号的价值。五个长期积累对话历史的老号，值得；五个随时能重开的测试号，小组独享就够。判断标准是重开一个号的成本，超过一个月线路费差额就上独享。</p>
<h3>抖动是线路问题还是本机问题？</h3>
<p>答：先排除本机。同一台机器直连和走代理各测一轮，如果直连也抖，问题在本地网络；如果只有走代理时抖，问题在线路。两轮测试各跑二十分钟就能分清。</p>
<h3>池子多大才算够？</h3>
<p>答：按同时在线的号数看，池子是活跃号的二十倍以上，撞车率就比较低了。低于十倍时，分配策略要更谨慎，尽量按城市分散取号。</p>
<h3>便宜方案加个监控能补回来吗？</h3>
<p>答：能补一部分，主要是及时发现而不是避免。监控能让你在抖动开始时切备用线，但切线的动作本身也要成本。监控是减损手段，不是替代方案。</p>
